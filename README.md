# LIMBÉ × Design Offices – Community Get Together

## Veröffentlichung über GitHub Pages
Alle Dateien und den Ordner `assets` gemeinsam in das Repository hochladen. In GitHub unter Settings → Pages den Branch `main` und `/ (root)` auswählen.

## Echte Interessensregistrierung aktivieren (Formspree)
1. Auf https://formspree.io ein Konto erstellen und ein Formular für LIMBÉ anlegen.
2. Im Formspree-Dashboard die gewünschte Empfänger-E-Mail hinterlegen bzw. verifizieren und Benachrichtigungen prüfen.
3. Den Endpunkt `https://formspree.io/f/xxxxxxxx` kopieren.
4. In `index.html` genau `https://formspree.io/f/DEINE_FORM_ID` durch den echten Endpunkt ersetzen.
5. Dateien zu GitHub hochladen und mit einer Testanmeldung prüfen, ob sie im Formspree-Dashboard und als E-Mail-Benachrichtigung ankommt.

**Wichtig:** Ohne echte Formspree-ID sendet das Formular bewusst nichts und zeigt einen Hinweis. Erst nach erfolgreicher Serverantwort erscheint die Erfolgsmeldung.

## Datenschutz / Freigabe
Vor Veröffentlichung ein gültiges Impressum und eine Datenschutzerklärung verlinken. In der Datenschutzerklärung die Datenverarbeitung über Formspree (inkl. ggf. internationaler Übermittlung) transparent erläutern und die rechtlichen Voraussetzungen prüfen. Die Einwilligung im Formular bezieht sich nur auf die Kontaktaufnahme zu diesem Event, nicht auf Werbung oder Newsletter.

Das Formular sammelt Name, E-Mail, optional Unternehmen und die Zustimmung zur Kontaktaufnahme. Keine +1-Abfrage, keine Terminbuchung, keine Zahlung.
